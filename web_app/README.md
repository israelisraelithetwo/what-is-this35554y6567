# 🎙️ מערכת המרת טקסט לדיבור (TTS) עם שיבוט קול

מערכת ווב פשוטה וידידותית להמרת טקסט לדיבור ושיבוט קול, עם תמיכה מלאה בעברית.

## 📋 מה המערכת עושה?

המערכת מאפשרת:
- **המרת טקסט לדיבור**: הקלד טקסט בעברית (או בכל שפה אחרת) וקבל קובץ אודיו
- **שיבוט קול**: העלה דגימת קול קצרה וסנתז טקסט בקול הזה
- תמיכה במודלים מתקדמים: YourTTS (ברירת מחדל) ו-XTTS v2
- תמיכה מלאה בעברית ושפות רבות נוספות

## 🚀 הפעלה מהירה (Windows - ללא צורך בטרמינל)

### אפשרות 1: הקלק כפול (הכי פשוט!)

1. ודא ש-Docker Desktop מותקן ופועל במחשב שלך
2. עבור לתיקייה `web_app`
3. **הקלק פעמיים** על הקובץ `run_tts.bat`
4. המתן עד שהבנייה תסתיים (בפעם הראשונה זה יקח כמה דקות)
5. פתח דפדפן וגש לכתובת: http://localhost:5002/static/index.html

### אפשרות 2: Docker Desktop GUI

1. פתח את Docker Desktop
2. גש ללשונית "Containers"
3. לחץ על "+" ובחר "Import from file"
4. בחר את הקובץ `docker-compose.yml` מתיקיית `web_app`
5. לחץ על "Deploy"

## 💻 הפעלה עם שורת פקודה (למתקדמים)

### דרישות מוקדמות
- Docker Desktop מותקן ופועל
- (אופציונלי) Python 3.10+ להרצה מקומית ללא Docker

### הפעלה עם Docker (מומלץ)

```bash
cd web_app
docker compose up --build
```

לאחר שהשרת עולה, פתח דפדפן וגש לכתובת:
```
http://localhost:5002/static/index.html
```

### הפעלה מקומית ללא Docker (למפתחים)

```bash
cd web_app
python -m venv venv
source venv/bin/activate  # Linux/Mac
# או
venv\Scripts\activate  # Windows

pip install -r requirements.txt
pip install TTS

python -m uvicorn server:app --host 0.0.0.0 --port 5002
```

## 📖 איך להשתמש במערכת?

### 1. בחירת מודל
- **YourTTS** (ברירת מחדל) - מהיר יותר, מתאים ל-CPU
- **XTTS v2** - איכות גבוהה יותר, עשוי להיות איטי יותר על CPU

### 2. המרת טקסט לדיבור
1. הקלד או הדבק טקסט בשדה "טקסט"
2. בחר קוד שפה (he לעברית, en לאנגלית, וכו')
3. לחץ על כפתור "סנתז דיבור"
4. המתן לעיבוד (בפעם הראשונה יקח זמן בזמן הורדת המודל)
5. האזן לתוצאה והורד את הקובץ אם תרצה

### 3. שיבוט קול
1. הקלד טקסט בשדה "טקסט" תחת שיבוט קול
2. העלה קובץ אודיו קצר (עד 15 שניות, מקסימום 5MB) של הדובר
   - פורמטים נתמכים: WAV, MP3, FLAC, OGG
   - עדיף קובץ ברור ונקי ללא רעשי רקע
3. לחץ על כפתור "שבט קול"
4. המתן לעיבוד
5. האזן לתוצאה והורד את הקובץ

## ⚙️ שימוש ב-API (למפתחים)

### סינתזה של טקסט לדיבור

```bash
curl -X POST http://localhost:5002/synthesize \
  -F "text=שלום עולם, זה מבחן של המרת טקסט לדיבור" \
  -F "model_name=your_tts" \
  -F "language=he" \
  --output output.wav
```

### שיבוט קול

```bash
curl -X POST http://localhost:5002/clone \
  -F "text=זה טקסט בקול המשובט" \
  -F "speaker_wav=@/path/to/speaker.wav" \
  -F "model_name=your_tts" \
  -F "language=he" \
  --output cloned.wav
```

### בדיקת בריאות השרת

```bash
curl http://localhost:5002/health
```

### רשימת מודלים זמינים

```bash
curl http://localhost:5002/models
```

## ⚠️ מידע חשוב

### הרצה ראשונה
- **בפעם הראשונה** המערכת תוריד את המודלים אוטומטית מהאינטרנט
- המודל YourTTS שוקל כ-300MB - ההורדה תקח מספר דקות
- המודל XTTS v2 שוקל כ-1.8GB - ההורדה תקח יותר זמן
- המודלים נשמרים במטמון ולא יורדו שוב בהרצות הבאות

### ביצועים
- **CPU**: המערכת מותאמת לעבוד על CPU בלבד
  - זמן עיבוד: 10-30 שניות למשפט בודד (תלוי באורך)
  - המודל YourTTS מהיר יותר מ-XTTS v2
- **GPU** (אופציונלי): אם יש לך כרטיס מסך NVIDIA עם CUDA:
  - העיבוד יהיה מהיר משמעותית (פי 5-10)
  - צריך להתקין את `nvidia-docker` ולהגדיר את Docker בהתאם

### מגבלות
- **גודל קובץ אודיו**: מקסימום 5MB (כ-15 שניות)
- **אורך טקסט**: מקסימום 5000 תווים
- **פורמטים נתמכים**: WAV, MP3, FLAC, OGG

### עצירת השרת

**Windows (הקלק כפול):**
- סגור את החלון או לחץ Ctrl+C

**Docker Desktop:**
- לחץ על כפתור "Stop" בממשק

**שורת פקודה:**
```bash
docker compose down
```

## 🔧 פתרון בעיות

### השרת לא עולה
1. ודא ש-Docker Desktop פועל
2. בדוק שפורט 5002 לא תפוס על ידי תוכנה אחרת
3. הפעל מחדש את Docker Desktop

### שגיאת "TTS library not available"
- המערכת צריכה לרוץ דרך Docker
- אם אתה מריץ מקומית, התקן: `pip install TTS`

### העיבוד לוקח הרבה זמן
- זה נורמלי בהרצה על CPU
- בפעם הראשונה ייקח יותר זמן בגלל הורדת המודלים
- שקול להשתמש במודל YourTTS במקום XTTS v2 לביצועים טובים יותר

### הקול המשובט לא דומה למקור
- ודא שקובץ האודיו נקי וברור
- השתמש בקובץ של 5-15 שניות (לא יותר מדי קצר)
- נסה מודל אחר (XTTS v2 בדרך כלל טוב יותר לשיבוט)
